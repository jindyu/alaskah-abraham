# 아브라함 (Abraham) — 6권 46장 전편 챕터 카탈로그

본 문서는 `alaskah-abraham`의 전체 서사 구조와 챕터별 플레이 유형, 등장인물, 배경 무대, 상호작용 명세를 정의하고 진행 상태를 추적한다.

- **030_the_axe**: [Playable Loop] 제4장 · 도끼 (밤의 공방에서 도끼를 들어 우상들을 부수고 큰 우상 손에 쥐여주기)

- **060_night_escape**: [Playable Loop] 제7장 · 밤중의 탈출 (데라, 사래, 어린 롯과 함께 봇짐 챙겨 우르 탈출)
- **070_haran**: [Hybrid] 제8장 · 하란 (하란 캠프 정착, 데라의 임종과 애도)
- **080_grandfathers_confession**: [Cutscene - Coda] 제9장 · 아브라함의 장막 (먼 훗날, 노년 아브라함이 에서에게 전하는 이야기)
- **090_esaus_sword**: [Playable Loop - Coda] 제10장 · 들판 (에서 조작: 사냥터 니므롯 조우 및 가죽옷 챙겨 야간 도주)
- **100_lentil_stew**: [Hybrid - Coda] 제11장 · 장막 (에서 조작: 야곱의 붉은 팥죽과 장자권 맹세)
